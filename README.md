# Unity 2D Game (TP1)

2D game built with Unity and C#, developed as a team project (TP1) for university coursework at the Instituto Politécnico de Viana do Castelo (IPVC), April – May 2025.

Together with [Overlord Rising](https://github.com/alexandresilva-dev/TP2-28243-28258) (Phaser 3), this is one of the two academic 2D games covering game loops, physics, collision handling, level design and collaborative development with Git.

## Tech stack

- Unity (2D)
- C#
- Git / GitHub for version control

## Repository contents

```
TP1-28243-28258/
├── Unity/        # Unity project (open this folder in Unity Hub)
└── tp1.zip       # Original submission archive
```

## Running the game

1. Open Unity Hub and add the `Unity/` folder as a project.
2. Open the main scene and press Play in the editor.

## Academic context

Team project developed with a classmate for a university course. The source code (comments, identifiers and some file names) is kept in Portuguese, exactly as originally submitted.
